# tQwQ 品牌資產

這個資料夾保存專案目前核准使用的點陣品牌資產。每個檔案都是獨立輸出，使用時不需要從品牌展示板裁切。

| 檔案 | 用途 | 尺寸／格式 |
|---|---|---|
| `primary-logo.png` | 文件、簡報與一般品牌識別 | 1693×929 PNG |
| `readme-header.png` | repository `README.md` 頂部橫幅 | 1774×887 PNG |
| `org-avatar-512.png` | GitHub Organization 頭像 | 512×512 PNG |
| `mascot-sticker-transparent.png` | README、公告與貼圖使用 | 1254×1254 透明 PNG |
| `social-preview-1280x640.jpg` | GitHub repository Social preview | 1280×640 JPEG |

## 色彩

- Deep Navy：`#173A5E`
- Sky Aqua：`#62D7E8`
- Ice Blue：`#C9F4F8`
- Star Yellow：`#FFD45A`
- Cream White：`#FFFDF5`

## 使用原則

- GitHub Organization 頭像使用 `org-avatar-512.png`，不要把橫式 logo 硬裁成正方形。
- README 使用 `readme-header.png`；社群連結預覽使用實色背景的 `social-preview-1280x640.jpg`。
- 正式 logo 保持簡潔。較多星點或角色表情留給橫幅、貼圖與公告素材。
- 不要改變 `tQwQ` 的大小寫或拼法，也不要拉伸、壓扁或重新上色。

## GitHub 設定不在 Git 歷史內

GitHub Organization 頭像與 repository Social preview 必須在 GitHub 設定頁另外上傳；合併這些檔案不會自動改變 GitHub UI。把同一份檔案收進 repository，是為了讓來源、review 與未來替換都有版本紀錄。

## 向量來源狀態

這一版是可直接使用的 PNG／JPEG 資產，不是正式的可編輯 SVG 原稿。乾淨的 symbol、wordmark 與橫式 lockup 向量來源會在後續品牌 issue 中另外製作與 review。
